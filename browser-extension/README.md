# FrikiVault · ActionFigure411

Este puente permite que FrikiVault consulte ActionFigure411 desde tu Chrome real, en lugar de hacerlo desde un servidor de Vercel.

## Instalar una sola vez

1. Descomprime la carpeta de la extensión.
2. Abre `chrome://extensions`.
3. Activa **Modo de desarrollador**.
4. Pulsa **Cargar descomprimida**.
5. Selecciona la carpeta que contiene `manifest.json`.

Después vuelve a FrikiVault. Las figuras no Funko consultarán ActionFigure411 automáticamente.

## Qué hace

- Solo escucha peticiones de FrikiVault.
- Abre ActionFigure411 en una pestaña no activa.
- Entra en la sección correcta (Marvel, Star Wars, DC, etc.).
- Usa el cuadro Search de la propia página.
- Abre la ficha elegida y lee la media de ventas, High/Low y Buy It Now.
- Cierra la pestaña al terminar.
- Guarda el resultado localmente durante 12 horas para no repetir consultas.
- Si ActionFigure411 muestra una verificación, se detiene; no intenta saltarla.
